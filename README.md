Setup (one-time)
Run /setlanguage → pick your native language from the dropdown. That's it — the bot handles everything automatically after that.

Commands
/setlanguage — Pick your native language (Japanese, Spanish, French, etc.)
/mylanguage — Check what language you currently have set
/clearlanguage — Reset back to English default
/translate [text] [target] — Manually translate any text, e.g. /translate hello ja translates "hello" to Japanese
/languages — See all supported language codes

How auto-translation works

You write in your native language → bot posts an English translation in the channel for everyone to see
Someone writes in English → bot DMs you the translation in your language
No language set → any non-English message gets auto-translated to English in the channel


Tips

Make sure your DMs are open (Server Settings → Allow DMs) or the bot can't send you private translations
You only need to run /setlanguage once — it remembers your preference
